結論：「高価買取」より、確かめられる事実で選ぶ

多くの買取店が「高価買取」をうたっているため、広告の言葉だけでは差が分かりません。選ぶときは、売る前に自分で確かめられる次の6点を見てください。

  1. 古物商許可の表示があるか
  2. 手数料を引いた後の受取額が分かるか
  3. 査定額の理由を説明してくれるか
  4. 売りたい品物の買取に対応しているか
  5. 本人確認をきちんと行っているか
  6. 売り方（店頭・宅配・出張）に応じた条件が明確か

1. 古物商許可の表示があるか

中古品を買い取る店は、都道府県の公安委員会から古物商の許可を受けています。ホームページで取引する場合は、「許可を受けた公安委員会名」「許可証番号」「氏名または名称」を表示する必要があります（警視庁）。

サイトのフッターや会社概要にこの表示があるかを確認してください。店頭では、店内に許可番号の掲示があるかも見てみましょう。

2. 手数料を引いた後の受取額が分かるか

買取店の手数料の扱いは、大きく2通りです。

  • 買取価格とは別に手数料を引く
  • 手数料を買取価格に含め、「手数料無料」と表示する

どちらが得かは、表示だけでは判断できません。比べるときは、最終的に手元に入る金額を各店に確認してください。宅配買取なら、送料や振込手数料、キャンセル時の返送料も含めて確認します。

3. 査定額の理由を説明してくれるか

信頼できる店は、金額だけでなく、その金額になった理由を説明できます。たとえば次のような点です。

  • 貴金属：その日の相場、純度、重さ
  • ブランド品・時計：型番、状態、付属品の有無、市場での需要

「この金額です」とだけ言われたときは、内訳を尋ねてください。金の計算方法は「金の買取相場の見方」で解説しています。

4. 売りたい品物の買取に対応しているか

店によって得意な品物や、買取の条件が違います。壊れた品や付属品のない品を買い取るかどうかも、店ごとに判断が分かれます。持ち込む前に、対象になるかを写真や電話で確かめると無駄足を防げます。

5. 本人確認をきちんと行っているか

古物商は、買取の合計が1万円以上などの場合、売る人の住所・氏名・職業・年齢を確認することが法律で義務付けられています（警視庁）。身分証の提示を求められるのは、法律を守って営業している証拠です。

宅配買取では、身分証のコピーを送るだけでは法律上の確認として不十分です（警視庁）。本人限定の郵便やオンラインでの本人確認など、決まった手順を案内する店を選びましょう。

6. 売り方に応じた条件が明確か

売り方向いている人確認したいこと
店頭買取その場で説明を聞きたい、すぐ現金化したい人営業時間、予約の要否、持参する身分証
宅配買取近くに店がない人、時間が取れない人送料、キャンセル時の返送料、本人確認の手順、入金までの日数
出張買取品物が多い人、運べない人出張費、来訪前の説明、契約書面の交付

出張買取は、法律上の「訪問購入」にあたります。契約書面を受け取った日から8日間はクーリング・オフができ、その期間は品物の引き渡しを拒むこともできます（東京都 東京くらしWEB）。呼んでもいないのに訪問して買取を勧める「飛び込み勧誘」は禁止されています（消費者庁）。

ただし、自動車（二輪を除く）、家具、洗濯機や冷蔵庫などの家電、本・CD・DVD・ゲームソフト類、有価証券は、訪問購入の規制の対象外です（東京都 東京くらしWEB）。

見積もりを比べるときの手順

  1. 品物の情報を整理する（型番・刻印・重さ・付属品・購入時期）
  2. 2〜3店に同じ情報と写真で査定を依頼する
  3. 手数料・送料を引いた受取額をそろえて比べる
  4. 査定額の理由を聞き、納得できた店で売る

写真での査定額は、実物を確認した後に変わることがあります。最終的な金額で判断してください。

ナニウルも同じ基準で確かめてください

ナニウルは八王子の買取店です。買取には手数料をいただいています。査定の際は手数料の金額も含めて確認し、他店と比べてください。本人確認は、買取金額にかかわらず必ず行っています。なお、壊れた品物は買取の対象外です。
